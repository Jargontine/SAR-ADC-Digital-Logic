# SAR ADC — 12-bit Digital Logic Controller

RTL implementation of the digital control block for a 12-bit Successive Approximation Register ADC. Generates all timing and control signals for co-simulation with an analog CDAC and comparator in Cadence Spectre-Verilog. Developed as part of a mixed-signal chip design project at Columbia University.

---

## Overview

The SAR ADC performs analog-to-digital conversion through binary search. The digital controller generates a startup sequence to condition the analog circuitry, then runs 12 successive bit-decision cycles — each testing one bit from MSB (b11) to LSB (b0). The comparator result is captured on the falling edge of `sar_data_samp` and used to keep or clear the corresponding pcode bit. After 12 decisions, `adc_out` holds the final 12-bit digital result.

---

## Signal Interface

| Direction | Signal | Description |
|---|---|---|
| IN | `master_clk` | 8 MHz master clock |
| IN | `sar_pdnb` | Active-low reset and enable |
| IN | `sar_cmp_out` | 1-bit comparator result from analog block |
| OUT | `sarclk_cds_vref` | 5µs pulse to enable voltage reference generator |
| OUT | `sar_cmp_pdnb` | Comparator enable — rises when Vref is ready |
| OUT | `sar_cmp_cdsamp1/2/3` | Comparator input sampling phases |
| OUT | `sar_dac_smp_vcm` | DAC common-mode sample — BclK starts on falling edge |
| OUT | `sar_BclK` | Virtual bit clock — generated internally (10µs period) |
| OUT | `sar_Vrefset[11:0]` | One-hot bit-under-test indicator |
| OUT | `sar_cmp_clk` | Fires comparator at BclK falling edge (3µs wide) |
| OUT | `sar_cmp_ltch_disable` | Latches comparator output (2µs, offset +1µs from cmp_clk) |
| OUT | `sar_data_samp` | Sample strobe — cmp_out captured on falling edge |
| OUT | `sar_smp_unitcap` | Unit capacitor enable — HIGH entire conversion |
| OUT | `dac_pcode[11:0]` | CDAC positive control — accumulates final answer |
| OUT | `dac_ncode[11:0]` | CDAC negative control — always complement of pcode |
| OUT | `adc_out[11:0]` | Final 12-bit conversion result |

> `sar_dac_smp_vin` is NOT generated by this block — driven by analog side.

## Timing — Per Bit Cycle (1 MHz reference)

| Event | Time | Description |
|---|---|---|
| BclK rise | t + 0µs | Vrefset asserts current bit, pcode bit set |
| BclK fall | t + 5µs | sar_cmp_clk rises — comparator makes decision |
| ltch_disable rise | t + 6µs | Comparator output frozen |
| data_samp rise | t + 7µs | Sample strobe asserted |
| **data_samp fall** ⚠ | **t + 8µs** | **cmp_out captured — bit decision applied to pcode** |
| Vrefset transition | t + 9µs | Direct handoff to next bit — no gap |

---

## Bit Decision Rule

```verilog
// Inverted polarity — differential CDAC architecture
if (sar_cmp_out == 1)   // input < reference
    pcode[bit] = 0;     // bit = 0 — clear pcode, set ncode
else                    // input > reference
    pcode[bit] = 1;     // bit = 1 — keep pcode HIGH
```

## Clock Architecture

```
master_clk  8 MHz  (125ns period — chip physical clock)
  ÷ CLK_DIV (default 8)
ref_tick    1 MHz  (1µs per tick — all SAR timing derived here)

// Programmable via CLK_DIV parameter
CLK_DIV = 8  →  1 MHz reference  (default)
CLK_DIV = 4  →  2 MHz reference
CLK_DIV = 16 →  500 kHz reference
CLK_DIV = 2  →  4 MHz reference
```

---

## State Machine

```
ST_IDLE    →  wait for sar_pdnb HIGH
ST_DELAY   →  5µs delay after pdnb rise
ST_SARCLK  →  sarclk_cds_vref pulse (5µs)
ST_SAMPLE  →  analog sampling phase (10µs) — cdsamp1/2/3, Vcm
ST_CONVERT →  12 × 10µs bit decision cycles → repeat immediately
```
